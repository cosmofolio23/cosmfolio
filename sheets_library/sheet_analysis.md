## 8. Design Evolution Path (Recommended Sheet Sequence)

**Project Discovery Phase:**
1. Site Analysis — Full Analytical (understand context)
2. Site Analysis — Climate & Environment (passive design drivers)
3. Mood Board — Classic Grid (material/aesthetic direction)

**Design Development Phase:**
4. Concept — Minimal Thesis (thesis statement)
5. Diagram — Massing Study (form development)
6. Floor Plan — Color-Zoned Program (program layout)

**Design Refinement:**
7. Section — Rendered Atmospheric (spatial quality)
8. Elevation — Rendered Facade (material expression)
9. Axonometric — Cutaway Interior (interior experience)

**Finalization:**
10. Presentation Board — Full Project A1 (complete summary)
11. Materials — Finish Schedule (FF&E specification)
12. Detail — Construction Detail Grid (technical execution)

## 9. Integration with Portfolio Creator

### Workflow for Architects Using Both:
1. **Portfolio Template** (from portfolio library) provides overall structure/style
2. **Individual Sheet Templates** (from sheets library) populate each portfolio page
3. **Sheet composer UI** lets architects:
   - Select sheet type (concept, plan, section, etc.)
   - Choose style variant (minimal, rendered, dark, etc.)
   - Upload content (renders, photos, diagrams)
   - Auto-generate sheet with content in correct zones

### Example Workflow:
```
Portfolio Template: "Nordic Minimal"
├── Cover Sheet (auto-generated)
├── Sheet 1: Concept — Minimal Thesis
├── Sheet 2: Site Analysis — Minimal Map Focus
├── Sheet 3: Floor Plan — Minimal Gallery

├── Sheet 5: Elevation — Rendered Facade
```
